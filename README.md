# News Agent

AI-powered news analytics & discovery platform.

**Live Demo:** https://news-agent-bay.vercel.app

**Features:**
- Real-time article filtering by topic
- AI-powered summaries using Groq API
- Reading history & analytics
- Dark/light mode
- PWA support (installable)

**Tech Stack:**
- Frontend: Next.js, React, Tailwind CSS
- Backend: Supabase (PostgreSQL)
- AI: Groq API, NewsAPI
- Deployment: Vercel

**How to run:**
```bash
npm install
npm run dev
```

Add your env variables in `.env.local`
